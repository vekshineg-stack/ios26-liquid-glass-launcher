# iOS 26 Setup Assistant — Android launcher

Проект Kotlin для POCO X6 Pro / Android 16. Это самостоятельный HOME-лаунчер с тёмно-серебристой темой, списком установленных приложений, двумя разделами (Favourites / App Library), быстрым запуском приложений, переходом к сведениям о приложении и установкой встроенных обоев.

## Что реализовано в версии 1.0

- Регистрируется как приложение рабочего стола Android (HOME).
- Получает список приложений с LAUNCHER intent.
- Раздел Favourites показывает выбранные популярные приложения (если они установлены), затем остальные.
- Раздел App Library группирует приложения по приблизительным категориям и показывает остальные.
- Нажатие запускает приложение; долгое нажатие открывает системную страницу сведений о приложении.
- Встроенные серебристые обои можно применить через меню «НАСТРОЙКА».
- Есть диагностическая проверка наличия Shizuku.

## Ограничения и честное описание Shizuku

Shizuku не превращает обычное приложение в системное и не гарантирует доступ к закрытым API HyperOS. Для работы самого лаунчера Shizuku не нужен. В этой версии он только проверяется; привилегированные команды намеренно не выполняются. Это исключает скрытое изменение системных настроек и нестабильные команды на HyperOS.

Android не предоставляет обычному стороннему приложению универсальный API для:
- программного создания/перестановки ярлыков внутри другого лаунчера;
- управления экраном блокировки Xiaomi;
- управления сторонними KWGT-виджетами как их владельцем;
- принудительного применения стороннего icon pack к системным приложениям.

Этот проект — базовый самостоятельный лаунчер, а не клон системной оболочки iOS и не автоматический модификатор HyperOS.

## Сборка APK локально

Требуется Android Studio с JDK 17 и Android SDK Platform 36.

1. Распакуйте архив.
2. Откройте папку проекта в Android Studio.
3. Дождитесь Gradle Sync.
4. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Командная сборка:
```bash
gradle assembleDebug
```

## Сборка через GitHub Actions

1. Создайте пустой репозиторий GitHub.
2. Загрузите содержимое архива в корень репозитория.
3. Откройте вкладку Actions.
4. Разрешите запуск Actions, если GitHub запросит.
5. Запустите workflow `Build Android APK` через Run workflow либо отправьте push в ветку `main`.
6. Откройте завершённый запуск и скачайте artifact `ios26-setup-assistant-debug`.
7. Распакуйте artifact — внутри будет `app-debug.apk`.

APK debug подписан тестовым ключом Android Gradle Plugin и предназначен для личной установки и тестирования. Для распространения нужна отдельная release-сборка с собственным ключом подписи.

## Установка на POCO X6 Pro

1. Перенесите `app-debug.apk` на телефон.
2. Откройте файл через «Проводник».
3. Разрешите установку из этого источника, если Android спросит.
4. Установите приложение.
5. Откройте Настройки → Приложения → Приложения по умолчанию → Рабочий стол.
6. Выберите `iOS 26 Setup Assistant`.
7. Для возврата выберите POCO Launcher в том же меню.

## Управление

- Кнопка HOME — избранные приложения.
- Кнопка APPS — библиотека приложений по категориям.
- Нажатие на приложение — запуск.
- Долгое нажатие — сведения о приложении.
- НАСТРОЙКА → «Установить встроенные обои» — применить фон.
- НАСТРОЙКА → «Выбрать системные обои» — открыть системный выбор обоев.

## Следующие шаги развития

Для настоящей автоматизации потребуется отдельно реализовать:
- редактируемый список избранного и пользовательские папки;
- drag-and-drop между страницами;
- полноценный музыкальный MediaSession widget;
- погодный источник с разрешением геолокации;
- импорт пользовательского wallpaper pack;
- резервное копирование конфигурации;
- отдельный безопасный Shizuku-модуль с явным подтверждением каждой операции.
